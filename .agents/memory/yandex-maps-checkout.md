name: Yandex Maps checkout
description: Демонстрационные ПВЗ вместо реальных операторов; адрес и координаты не разделять.
---

Владелец отменил подключение настоящих ПВЗ: нужны демонстрационные места на карте
для показа выбора адреса и оформления самовывоза, а не для настоящей доставки.

**Why:** Пользователь явно изменил назначение доставки: «не для реальной доставки,
но для показа реальной работы», при этом места обязательно должны быть привязаны
к адресам.

**How to apply:** Не возвращать требования доступа к API операторов как условие
работы демо-карты. Использовать настоящие пары адрес/координаты; не перемещать
маркер случайно относительно его адреса. Указывать демонстрационный статус в
выборе точки и сохранённом адресе заказа. Реальную доставку подключать только по
новому прямому запросу владельца.

Если владелец вновь запросит настоящую доставку, демонстрационные точки и
публичные sandbox-реквизиты операторов не заменяют production-доступ.

**Why:** Тестовый каталог не подтверждает возможность реальной доставки по договору.

**How to apply:** При новом подключении реального оператора проверять живой
каталог и окончательный статус отправления; не смешивать его с демонстрацией.
