---
name: Removing tracked database files
description: Удаление уже отслеживаемой и одновременно игнорируемой базы при автоматических checkpoint
---

Удаляя старую рабочую базу, которая уже отслеживается Git и теперь добавлена в `.gitignore`, фиксировать удаление через `git rm`, а не только удалять файл с диска.

**Why:** При автоматическом checkpoint физически удалённая SQLite восстановилась как отслеживаемый файл; добавление ignore-правил не вывело её из репозитория.

**How to apply:** После проверенного переноса и разрешённого удаления проверить отсутствие файла, пустой `git ls-files` для него и статус `D` в staged diff. Не переписывать Git-историю без отдельного согласия владельца.
