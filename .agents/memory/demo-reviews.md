---
name: Демонстрационные отзывы
description: Согласованный объём демо-отзывов, неизменность оценок и возможность оценки без текста.
---

Демонстрационные отзывы допустимы только с явной пометкой «Демо», отдельно от
настоящих отзывов. Количество показанных отзывов и оценок должно точно совпадать
с числом рядом с рейтингом каждого товара; не заменять эти числа общим лимитом
вроде 100 отзывов на товар. Существующие оценки товаров при демо-наполнении не менять.
Покупатель может оставить оценку без текста.

**Why:** Пользователь согласовал помеченные демонстрационные отзывы и уточнил:
«Отзывов должно быть ровно столько сколько и прописано рядом с оценкой
(оценки менять не надо). Покупатель ведь может просто оценить товар без отзыва».

**How to apply:** При изменении демо-наполнения сверять итоговые количества со
счётчиками товаров, не пересчитывать их оценки по вымышленным примерам, не создавать
ради наполнения фиктивных покупателей или заказов. Настоящие отзывы не подменять.
